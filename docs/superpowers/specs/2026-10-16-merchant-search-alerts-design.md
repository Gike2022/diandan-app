# 商家订单查询与新订单提醒

延续已授权的课程演示系统开发，保留 React、现有粉紫星空主题和商家布局。

## 查询

- 商家订单接口增加 orderNumber、dateFrom、dateTo；支持完整或部分订单号（字母数字，忽略大小写），与状态组合筛选，服务端统一计算分页及总数。
- 日期指下单日期，按北京时间自然日计算，开始日包含零点，结束日包含整天；支持单边日期。拒绝不存在的日期和倒置范围，使用绑定参数。
- 页面增加有明确标签的订单号、开始日期、结束日期及查询/重置按钮。状态仍可即时切换，其余字段点击查询生效；新筛选返回第一页。展示当前已应用条件，保留刷新、状态流转、拒单和分页行为。

## 提醒

选择沿用每 5 秒轮询，课程演示不引入 WebSocket 或消息队列。新增管理员专用待接单快照接口，读取全部已付款待接单订单的 ID 与订单号，避免受列表筛选、20 条分页或总数相同影响。无需数据库迁移。

在所有商家页面显示待接单数量与“查看待接单”入口，新增订单合并成一次提示弹窗。首次进入只显示已有数量；后续将成功响应与上一份快照比较，同一标签页的快照按管理员分开保存，切页、刷新及重复响应不重复提醒。失败时保留快照，显示同步异常和重试入口，恢复后补提醒仍待接单的新订单。提醒只在商家页面运行；后台浏览器可能限制轮询，回到页面时重新同步。

提醒入口进入默认待接单列表，并清除订单号和日期条件；接单或拒单后同步更新提醒数量。顾客和匿名用户不能调用提醒接口。

## 验证

真实 MySQL 集成测试覆盖订单号、日期边界、组合筛选、分页、无结果、错误参数与权限；Playwright 覆盖查询/重置、其他商家页面的新付款提醒、首次加载/刷新不重复提醒、数量相同但换单、失败恢复、查看待接单和移动端/桌面布局。随后顺序执行全部 API 与浏览器回归、类型检查和构建，测试仅使用独立测试库。
